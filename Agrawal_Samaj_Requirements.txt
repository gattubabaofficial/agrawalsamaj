4. ADMIN MODULE
==================================================

4.1 Dashboard
- Total Members Count
- Total Users Count
- Active Events
- Bhavan Bookings
- Donation Statistics

4.2 Member Management
- View all members
- View all user details regardless of privacy settings
- Add/Edit/Delete members
- Approve or reject registrations
- Classify users as:
  * Registered Member
  * Non-Member/Outsider

4.3 Event Management
- Create events
- Manage event schedules
- Manage ticket/pass pricing
- Generate QR passes
- Track attendance
- Manage volunteers and scanners

4.4 Booking Management
- Approve bookings
- Manage room availability
- Update cash payment status
- View booking history

==================================================
5. MEMBER MANAGEMENT
==================================================

5.1 Family System
- Each family will have a unique Family ID
- Already registered family and have unique Family Id
- Other family members must register using the same Family ID

5.2 Member Profile
Profile fields:
- First Name
- Surname
- Family ID
- Mobile Number
- Address
- Email Address
- Profession
- Profile Photo

5.3 Privacy Controls
Members and Users can choose visibility of:
- Mobile Number
- Email Address
- Address

Privacy Rules:
- Hidden information is not visible to other users
- Admin can always view all information

Non-Registered Members List:

==================================================
8. EVENT MANAGEMENT
==================================================

8.1 Event Schedule
Admin can define:
- Program start time
- Food serving time
- Session timings
- Event agenda

8.2 Event Pass System
- Passes sold through the website/app
- Admin defines pass price
- User selects number of passes
- Total amount calculated automatically
- Online payment support

8.3 QR Pass System
- Unique QR generated for each pass
- QR sent through WhatsApp
- QR scanned by admin/volunteer
- Once scanned, QR becomes invalid
- Duplicate entry not allowed

==================================================
9. BHAVAN BOOKING MODULE
==================================================

9.1 Online Booking
Users can book:
- Rooms
- Halls
- Facilities

9.2 Booking Process
- Check availability
- Select room/hall
- View floor plan
- Choose suitable room
- Submit booking request

9.3 Payment Options
- Online Payment
- Cash Payment

Cash Payment Workflow:
- Admin updates payment status after receiving payment

9.4 Public Visibility
Booking information visible on public website.
Actual booking and payment require login.

Redirection Logic:
- Logged-in users -> Dashboard Booking Module
- Non-logged-in users -> Login/Register first
